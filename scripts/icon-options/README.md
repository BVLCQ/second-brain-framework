# Opções de ícone do app Brain

Alternativas exploradas para o ícone do app (Dock e Aplicativos). O escolhido é `brainlib/assets/icon/brain.svg`
(traço grosso, legível a 64 px); aqui ficam as outras, para comparar ou trocar.

- `svg/` — fonte de cada opção (1024×1024, tile arredondado).
- `png/` — render de cada uma.
- `icns/` — o `.icns` pronto: para testar uma no Dock, copie para `Brain.app/Contents/Resources/AppIcon.icns`
  (depois `killall Dock`), ou troque o `brain.svg` da opção pelo de `brainlib/assets/icon/` e rode `brain app install`.
