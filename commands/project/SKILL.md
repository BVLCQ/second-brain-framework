# /project — um projeto

1. Identifique `PROJ-#` (título ou id). `./brain plan show` lista a árvore.
2. `./brain memory dossier PROJ-#` — **Leitura atual** montada na hora (Fase 5): ficha
   + decisões/entregas do projeto + trechos da memória com as tags do projeto.
3. Leia `FRESH/projects/PROJ-#.md` (rode `./brain render` se não existir).
4. No chat: progresso (calculado + declarado), saúde e o motivo, entregáveis, decisões ativas (quem/quando), minhas vs. waiting, próximo marco, evidência recente (artefatos).
5. Não proponha mudar a árvore aqui — isso é `/goal`. Ofereça `/share project PROJ-#` se o dono for falar com alguém.
