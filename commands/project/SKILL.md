# /project — um projeto

1. Identifique `PROJ-#` (título ou id). `./brain plan show` lista a árvore.
2. Leia `FRESH/projects/PROJ-#.md` (rode `./brain render` se não existir).
3. No chat: progresso (calculado + declarado), saúde e o motivo, entregáveis, decisões ativas (quem/quando), minhas vs. waiting, próximo marco, evidência recente (artefatos).
4. Não proponha mudar a árvore aqui — isso é `/goal`. Ofereça `/share project PROJ-#` se o dono for falar com alguém.
